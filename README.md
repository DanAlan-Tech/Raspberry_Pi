# 🍓 Raspberry Pi Projects

Welcome to my personal collection of Raspberry Pi projects! This repository serves as a centralized hub for all the hardware tinkering, automation scripts, media servers, and IoT experiments I’ve built using various Raspberry Pi models.

---

## 🛠️ Hardware & Environment

Most projects in this repository are developed and tested using the following setup:
* **Devices:** Raspberry Pi 4 Model B (4GB/8GB), Raspberry Pi Zero W, Raspberry Pi Pico
* **OS:** Raspberry Pi OS (Debian-based) / Ubuntu Server
* **Languages:** Python, Bash, Node.js (varies by project)
